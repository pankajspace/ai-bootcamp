## 4. Vendor security assurance

### SEC-4.2 Independent security assurance (2025 wording)
A vendor that stores or processes customer data must hold a **SOC 2 Type I or Type II** report, or an ISO/IEC 27001
certificate, or must have completed the Nimbu Mart security questionnaire to the satisfaction of Information
Security.

## 7. Identity and access

### SEC-7.1 Single sign-on (2025 wording)
Single sign-on is recommended for all tools and required for tools used by more than 50 employees.

## 9. Incidents

### SEC-9.3 Vendor incident history (2025 wording)
Vendors with a security incident in the last 12 months must be discussed with the Head of Information Security
before approval.
