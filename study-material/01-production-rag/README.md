# Production RAG from Scratch

A self-paced course by **Shivank Agrawal** (Future with Shivank).

1. Open **`Production_RAG_Course_Shivank_Agrawal.html`** in any modern browser (Chrome, Edge, Firefox, Safari).
   It works offline. Your progress, quiz answers and checklist are saved in the browser.
2. Follow the modules in order. Each module tells you which lab to run.
3. The labs and the production app are in the **`code/`** folder. Start with `code/README.md`
   (setup takes about 10 minutes and no API key is required).

```
Production_RAG_Course_Shivank_Agrawal.html   the course (15 modules, diagrams, 11 simulations, quizzes)
code/
  labs/        14 runnable lessons (lab00 ... lab13)
  rag_core/    the small RAG library the labs use
  app/         production service: FastAPI + Redis/RQ + Postgres/pgvector
  data/raw/    the fictional Nimbu Mart knowledge base (14 documents)
  eval/        33 golden questions for evaluation
```
