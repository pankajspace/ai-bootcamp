Hands-on guides

Build a real backend with Codex, one guide at a time

This is the practice track of my Codex course. We build one auction-house app from an empty folder to a production-style system with a database, concurrency control, real-time updates, background workers, a message queue, payments and tracing — and we do it by directing an AI coding agent, then reviewing and testing everything it writes. I assume you are new to backend engineering: every concept, command and prompt is explained where it appears.

Keep a guide open while you work. Every prompt and command has a Copy button, every step tells you what you should see, and ticking “Done” is remembered in this browser.
