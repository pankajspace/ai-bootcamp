Component evals in code: score an inventory agent's router, prompt, search and tools, then check the judge against a human

One warehouse "reorder advisor", evaluated part by part. Each file builds a small test set with known good answers, runs the agent on it, scores every answer, and prints a report you can read at a glance. A review screen and a short script then check whether the LLM judge agrees with a person.

How to run it

  1. Install the packages: pip install -r requirements.txt
  2. Copy .env.example to .env and put your key in it: OPENAI_API_KEY=sk-...
  3. Run any file: python langgraph_router.py, python prompt_evals_inventory.py, python rag_evals_inventory.py, python tool_evals_inventory.py
  4. Open annotator.html in a browser (double-click it; no server needed), upload a results CSV, review, download the feedback, then python judge_agreement.py prompt_eval_results_feedback.csv

langgraph_router.py: send each question to the right specialist

One model call decides the category; a second call, with a specialist's system prompt, writes the answer.

Dashed arrows = conditional edges (only one is taken). Drawn from the graph LangGraph itself reports, shown at the end of this section.

1. The router: the model must pick exactly one of three labels

def router(state):
    decision = router_llm.invoke([
        SystemMessage(content="Route the inventory query to one of: reorder, forecast, or supplier.\n"
                              "- reorder: reorder point, EOQ, safety stock, when to order\n"
                              "- forecast: demand prediction, adjusting forecasts\n"
                              "- supplier: comparing suppliers, lead times, vendor costs"),
        HumanMessage(content=state["query"]),
    ])
    return {"category": decision.category}

with_structured_output(Route) makes the reply a Route object whose category can only be "reorder", "forecast" or "supplier". No text parsing, and no chance of a fourth made-up label.

prompt_evals_inventory.py: is prompt Version 2 really better?

Nine tricky warehouse questions, two system prompts, and an LLM judge that marks every answer pass or fail on three criteria.

1. The golden dataset: questions with hidden traps

def evaluate_response(question, expected_answer, actual_response):
    """LLM-as-judge: strict binary scores (0 = Fail, 1 = Pass) plus a one-line reason."""
    eval_prompt = f"""Evaluate this inventory reorder advisor response with STRICT binary scoring (0=Fail, 1=Pass).

    Question: {question}
    Expected Key Points: {expected_answer}
    Actual Response: {actual_response}

    Be STRICT. Only give 1 if the criterion is fully met:
    - Accuracy: Is the reorder recommendation correct with NO errors or misleading statements? (0 or 1)
    - Clarity: Would a warehouse manager act on this WITHOUT further questions? (0 or 1)
    - Completeness: Does it address the SPECIFIC edge case or nuance in the question? (0 or 1)

    Respond ONLY with JSON in this exact shape:
    {{"Accuracy": 0 or 1, "Clarity": 0 or 1, "Completeness": 0 or 1, "Reason": "one short sentence"}}"""

    response = client.chat.completions.create(
        model=MODEL,
        reasoning_effort="none",
        response_format={"type": "json_object"},     # JSON mode: the reply is always valid JSON
        messages=[{"role": "user", "content": eval_prompt}],
    )
    verdict = json.loads(response.choices[0].message.content)
    scores = {m: 1 if verdict.get(m) in (1, "1", True) else 0 for m in METRICS}
    scores["Reason"] = str(verdict.get("Reason", ""))
    return scores

💡 How the judge works

  • It gets the question, the key points and the actual answer, and three strict yes/no questions. Yes/no is easier to apply consistently than a 1–10 score.
  • response_format={"type": "json_object"} forces valid JSON, so json.loads never fails.
  • The Reason is one sentence explaining the verdict. Without it you'd know that an answer failed, but not why.

Twelve policy passages, three RAG configurations, and two kinds of score: did we fetch the right passages, and is the answer right and grounded?

    return np.array([item.embedding for item in response.data])
rag_evals_inventory.py · lines 137–137
doc_embeddings = embed(documents)                    # shape: (12, 1536)
rag_evals_inventory.py · lines 140–144
def retrieve(query, k=2):
    """Return the numbers of the k passages closest in meaning to the query."""
    q = embed([query])[0]
    sims = doc_embeddings @ q / (np.linalg.norm(doc_embeddings, axis=1) * np.linalg.norm(q))
    return [int(i) for i in np.argsort(sims)[::-1][:k]]      # highest cosine similarity first

Each passage becomes a list of 1,536 numbers that captures its meaning. For a question, we embed it the same way and pick the k passages with the highest cosine similarity (closest in meaning). doc_embeddings @ q scores all 12 passages in one line.

3. The RAG agent and the three configurations

def rag_agent(question, k=2, prompt_template=PROMPT_MINIMAL):
    """RAG agent: retrieve k passages, then answer from them."""
    doc_ids = retrieve(question, k=k)
    context = "\n---\n".join(documents[i] for i in doc_ids)
    prompt = prompt_template.format(context=context, question=question)
    response = client.chat.completions.create(
        model=MODEL,
        reasoning_effort="none",
        messages=[{"role": "user", "content": prompt}],
    )
    return {"doc_ids": doc_ids, "context": context, "answer": response.choices[0].message.content}

def recall_at_k(retrieved, relevant):
    """Share of the needed passages that were actually retrieved (1.0 = all of them)."""
    return len(set(retrieved) & set(relevant)) / len(relevant)

Recall@k needs no model: we know which passages each question needs (relevant_docs), so we just check how many were fetched. The LLM judge then scores three things: was the context enough (Relevance), does every claim come from the context (Groundedness), and does the answer match the reference (Correctness).

@tool
def eoq_calculator(annual_demand: float, ordering_cost: float, holding_cost_per_unit: float) -> str:
    """Calculate Economic Order Quantity: EOQ = sqrt(2 * D * S / H)."""
    if holding_cost_per_unit <= 0:
        return "Error: holding cost must be > 0"
    eoq = math.sqrt(2 * annual_demand * ordering_cost / holding_cost_per_unit)

            if isinstance(m, AIMessage):
                for tc in m.tool_calls:

                if m.usage_metadata:                             # real token counts from OpenAI

                actual_tools.append(tc["name"])
                text = str(m.content)
                tool_logs.append(ToolCallLog(

                    success=m.status != "error" and "error" not in text.lower(),

                ))
        output = messages[-1].text
    except Exception as e:
        error = str(e)

    return TaskEvaluation(

        expected_tools=expected, actual_tools=actual_tools, tool_call_logs=tool_logs,
        output=output, error=error,

💡 Read it in this order

  1. Run the agent once and time it.
  2. Every AIMessage holds the model's tool requests and its real token counts.
  3. Every ToolMessage is a tool that actually ran: we record its name, arguments, output, whether it errored, and whether it was one of the expected tools.
  4. The last message is the final answer.

def compute_precision(results: List[TaskEvaluation]) -> Dict:
    """Precision = correct tool calls / all tool calls made."""
    total_calls = sum(len(r.actual_tools) for r in results)
    correct_calls = sum(log.is_correct for r in results for log in r.tool_call_logs)
    per_task = []
    for r in results:
        if r.actual_tools:
            per_task.append(sum(log.is_correct for log in r.tool_call_logs) / len(r.actual_tools))
        else:
            per_task.append(1.0 if not r.expected_tools else 0.0)
    return {"overall_precision": correct_calls / total_calls if total_calls else 1.0,
            "avg_task_precision": sum(per_task) / len(per_task)}

def compute_recall(results: List[TaskEvaluation]) -> Dict:
    """Recall = expected tools that were called / all expected tools."""
    total_expected = sum(len(r.expected_tools) for r in results)
    per_task, recalled_total = [], 0
    for r in results:
        if r.expected_tools:
            recalled = min(sum(1 for t in r.actual_tools if is_correct_tool(t, r.expected_tools, r.acceptable_alternatives)),
                           len(r.expected_tools))
            recalled_total += recalled
            per_task.append(recalled / len(r.expected_tools))
        else:
            per_task.append(1.0 if not r.actual_tools else 0.0)
    return {"overall_recall": recalled_total / total_expected if total_expected else 1.0,
            "avg_task_recall": sum(per_task) / len(per_task)}

def compute_attribution(results: List[TaskEvaluation]) -> Dict:
    """Did the final answer actually USE a tool's result? Check the tool's main number appears in it."""
    tool_required = [r for r in results if r.requires_external_data]
    attributed = 0
    for r in tool_required:
        answer_numbers = numbers_in(r.output or "")
        for log in r.tool_call_logs:
            tool_numbers = numbers_in(log.output)
            if tool_numbers and any(abs(tool_numbers[0] - a) < 0.05 for a in answer_numbers):
                attributed += 1
                break
    n = len(tool_required)
    return {"attribution_rate": attributed / n if n else 0.0}

def cohens_kappa(a, b):
    """Agreement between two raters, after removing the agreement expected by chance."""
    n = len(a)
    observed = sum(x == y for x, y in zip(a, b)) / n
    labels = set(a) | set(b)
    chance = sum((a.count(l) / n) * (b.count(l) / n) for l in labels)
    kappa = (observed - chance) / (1 - chance) if chance < 1 else 1.0
    return observed, chance, kappa

Known limits (good discussion points)

  1. The judge grades its own model. The advisor and the judge are both gpt-6-luna; models can be lenient on answers written in their own style. A larger model as judge is a common upgrade, and judge_agreement.py tells you whether it helped.
  2. Small test sets. 9 prompt questions and 5 RAG questions: one answer moves a score by 11–20 points. Set NUM_QUESTIONS = 10 in the RAG file, and grow the sets over time.
  3. Pass/fail hides partial credit. That's the price of consistency; the judge's reason gives back some of the detail.
  4. The router has no "other" route. "What's the weather?" is forced into reorder, forecast or supplier.
  5. Some test labels are debatable. Scenario 9 expects eoq_calculator for pure arithmetic, and relevant_docs says passage 1 is needed for the supplier question. Gold sets need review too.
  6. Attribution is still a heuristic. It checks that the tool's main number appears in the answer; an answer that rounds 707.1 to "about 700" counts as not using the tool.
  7. Two precision numbers. The summary counts every call (so calling a tool twice counts twice); the per-task table compares sets of tool names. Both are fair; just say which one you mean.
  8. The annotator keeps nothing until you download. Closing the tab loses unsaved reviews, so download as you go.

LangGraph router: send each inventory question to the right specialist.
By Shivank Agarwal. Model: OpenAI gpt-6-luna.

    router ──► reorder  ──► END
           ├─► forecast ──► END
           └─► supplier ──► END

The router is one component of the agent, so it can be evaluated on its own:
did each question reach the right specialist?
"""
from typing import Literal, TypedDict

from dotenv import load_dotenv
from langchain_core.messages import HumanMessage, SystemMessage
from langchain_openai import ChatOpenAI
from langgraph.graph import END, StateGraph
from pydantic import BaseModel

load_dotenv()                                        # reads OPENAI_API_KEY from .env

llm = ChatOpenAI(model="gpt-6-luna", reasoning_effort="none")


def ask(system, user):
    """One model call with a system prompt; returns the reply as plain text."""
    return llm.invoke([SystemMessage(content=system), HumanMessage(content=user)]).text


# ---------- 1. The router: the model must pick exactly one of three labels ----------
class Route(BaseModel):
    category: Literal["reorder", "forecast", "supplier"]


router_llm = llm.with_structured_output(Route)       # the reply is parsed into a Route object


class State(TypedDict):
    query: str
    category: str
    response: str


def router(state):
    decision = router_llm.invoke([
        SystemMessage(content="Route the inventory query to one of: reorder, forecast, or supplier.\n"
                              "- reorder: reorder point, EOQ, safety stock, when to order\n"
                              "- forecast: demand prediction, adjusting forecasts\n"
                              "- supplier: comparing suppliers, lead times, vendor costs"),
        HumanMessage(content=state["query"]),
    ])
    return {"category": decision.category}


# ---------- 2. Three specialists: same model, different system prompts ----------
def reorder_node(state):
    answer = ask("You are an inventory reorder specialist. Answer concisely using inventory "
                 "principles like ROP, EOQ, and safety stock.", state["query"])
    return {"response": answer}


def forecast_node(state):
    answer = ask("You are a demand forecasting specialist. Answer concisely using concepts like "
                 "rolling averages, seasonality, and trend.", state["query"])
    return {"response": answer}


def supplier_node(state):
    answer = ask("You are a supplier management specialist. Answer concisely using concepts like "
                 "lead time, total cost, and vendor reliability.", state["query"])
    return {"response": answer}


def route_edge(state):
    return state["category"]                         # the label decides which node runs next


# ---------- 3. Wire the graph ----------
graph = StateGraph(State)
graph.add_node("router", router)
graph.add_node("reorder", reorder_node)
graph.add_node("forecast", forecast_node)
graph.add_node("supplier", supplier_node)

graph.set_entry_point("router")
graph.add_conditional_edges("router", route_edge,
                            {"reorder": "reorder", "forecast": "forecast", "supplier": "supplier"})
graph.add_edge("reorder", END)
graph.add_edge("forecast", END)
graph.add_edge("supplier", END)

def evaluate_response(question, expected_answer, actual_response):
    """LLM-as-judge: strict binary scores (0 = Fail, 1 = Pass) plus a one-line reason."""

        model=MODEL,
        reasoning_effort="none",

def embed(texts):
    response = client.embeddings.create(model=EMBED_MODEL, input=texts)
    return np.array([item.embedding for item in response.data])


doc_embeddings = embed(documents)                    # shape: (12, 1536)


def retrieve(query, k=2):
    """Return the numbers of the k passages closest in meaning to the query."""
    q = embed([query])[0]
    sims = doc_embeddings @ q / (np.linalg.norm(doc_embeddings, axis=1) * np.linalg.norm(q))
    return [int(i) for i in np.argsort(sims)[::-1][:k]]      # highest cosine similarity first

def rag_agent(question, k=2, prompt_template=PROMPT_MINIMAL):
    """RAG agent: retrieve k passages, then answer from them."""
    doc_ids = retrieve(question, k=k)
    context = "\n---\n".join(documents[i] for i in doc_ids)
    prompt = prompt_template.format(context=context, question=question)
    response = client.chat.completions.create(
        model=MODEL,
        reasoning_effort="none",
        messages=[{"role": "user", "content": prompt}],
    )
    return {"doc_ids": doc_ids, "context": context, "answer": response.choices[0].message.content}

@tool
def reorder_point_calculator(avg_daily_demand: float, lead_time_days: float, safety_stock: float = 0) -> str:
    """Calculate reorder point: ROP = (avg_daily_demand * lead_time_days) + safety_stock."""
    rop = avg_daily_demand * lead_time_days + safety_stock
    return f"Reorder Point = {rop:.1f} units (demand {avg_daily_demand}/day × {lead_time_days} days lead time + {safety_stock} safety stock)"


@tool
def eoq_calculator(annual_demand: float, ordering_cost: float, holding_cost_per_unit: float) -> str:
    """Calculate Economic Order Quantity: EOQ = sqrt(2 * D * S / H)."""
    if holding_cost_per_unit <= 0:
        return "Error: holding cost must be > 0"
    eoq = math.sqrt(2 * annual_demand * ordering_cost / holding_cost_per_unit)
    return f"EOQ = {eoq:.1f} units (D={annual_demand}, S=${ordering_cost}, H=${holding_cost_per_unit})"


@tool
def safety_stock_calculator(z_score: float, demand_std_dev: float, lead_time_days: float) -> str:
    """Calculate safety stock: SS = Z * σ_demand * sqrt(lead_time)."""
    ss = z_score * demand_std_dev * math.sqrt(lead_time_days)
    return f"Safety Stock = {ss:.1f} units (Z={z_score}, σ={demand_std_dev}, LT={lead_time_days} days)"


@tool
def days_of_supply_calculator(on_hand_units: float, avg_daily_demand: float) -> str:
    """Calculate days of supply remaining: DoS = on_hand / avg_daily_demand."""
    if avg_daily_demand <= 0:
        return "Error: daily demand must be > 0"
    dos = on_hand_units / avg_daily_demand
    return f"Days of Supply = {dos:.1f} days ({on_hand_units} units ÷ {avg_daily_demand} units/day)"


@tool
def abc_classifier(annual_spend_pct: float) -> str:
    """Classify an inventory item as A, B, or C based on its share of total annual spend (0-100)."""
    if annual_spend_pct >= 70:
        cls, desc = "A", "high-value — tight control, frequent review"
    elif annual_spend_pct >= 20:
        cls, desc = "B", "medium-value — moderate review"
    else:
        cls, desc = "C", "low-value — simplified control (but check criticality)"
    return f"Class {cls}: {annual_spend_pct:.1f}% of annual spend — {desc}"

def is_correct_tool(tool_name: str, expected_tools: List[str], alternatives: List[List[str]]) -> bool:
    return tool_name in expected_tools or any(tool_name in alt for alt in alternatives)


def run_evaluation(scenario: dict) -> TaskEvaluation:
    expected = scenario["expected_tools"]
    alternatives = scenario.get("acceptable_alternatives", [])
    actual_tools, tool_logs = [], []
    output, error = None, None
    input_tokens = output_tokens = 0
    t0 = time.time()
    try:
        result = agent.invoke({"messages": [{"role": "user", "content": scenario["question"]}]})
        messages = result["messages"]
        requested = {}                                           # tool_call_id -> the model's request
        for m in messages:
            if isinstance(m, AIMessage):
                for tc in m.tool_calls:
                    requested[tc["id"]] = tc
                if m.usage_metadata:                             # real token counts from OpenAI
                    input_tokens += m.usage_metadata["input_tokens"]
                    output_tokens += m.usage_metadata["output_tokens"]
            elif isinstance(m, ToolMessage):                     # one per tool that actually ran
                tc = requested.get(m.tool_call_id, {"name": m.name, "args": {}})
                actual_tools.append(tc["name"])
                text = str(m.content)
                tool_logs.append(ToolCallLog(
                    tool_name=tc["name"], parameters=tc["args"], output=text,
                    success=m.status != "error" and "error" not in text.lower(),
                    is_correct=is_correct_tool(tc["name"], expected, alternatives),
                ))
        output = messages[-1].text
    except Exception as e:
        error = str(e)

    return TaskEvaluation(
        question=scenario["question"], category=scenario["category"],
        expected_tools=expected, actual_tools=actual_tools, tool_call_logs=tool_logs,
        output=output, error=error,
        requires_external_data=scenario["requires_external_data"],
        optimal_tool_count=scenario["optimal_tool_count"], acceptable_alternatives=alternatives,
        input_tokens=input_tokens, output_tokens=output_tokens, latency_s=time.time() - t0,
    )

def compute_precision(results: List[TaskEvaluation]) -> Dict:
    """Precision = correct tool calls / all tool calls made."""
    total_calls = sum(len(r.actual_tools) for r in results)
    correct_calls = sum(log.is_correct for r in results for log in r.tool_call_logs)
    per_task = []
    for r in results:
        if r.actual_tools:
            per_task.append(sum(log.is_correct for log in r.tool_call_logs) / len(r.actual_tools))
        else:
            per_task.append(1.0 if not r.expected_tools else 0.0)
    return {"overall_precision": correct_calls / total_calls if total_calls else 1.0,
            "avg_task_precision": sum(per_task) / len(per_task)}


def compute_recall(results: List[TaskEvaluation]) -> Dict:
    """Recall = expected tools that were called / all expected tools."""
    total_expected = sum(len(r.expected_tools) for r in results)
    per_task, recalled_total = [], 0
    for r in results:
        if r.expected_tools:
            recalled = min(sum(1 for t in r.actual_tools if is_correct_tool(t, r.expected_tools, r.acceptable_alternatives)),
                           len(r.expected_tools))
            recalled_total += recalled
            per_task.append(recalled / len(r.expected_tools))
        else:
            per_task.append(1.0 if not r.actual_tools else 0.0)
    return {"overall_recall": recalled_total / total_expected if total_expected else 1.0,
            "avg_task_recall": sum(per_task) / len(per_task)}


def compute_avg_tool_calls(results: List[TaskEvaluation]) -> Dict:
    """How many calls per task, and how often that was too few, just right, or too many."""
    counts = {"too_few": 0, "optimal": 0, "too_many": 0}
    for r in results:
        n = len(r.actual_tools)
        key = "too_few" if n < r.optimal_tool_count else "optimal" if n == r.optimal_tool_count else "too_many"
        counts[key] += 1
    total = len(results)
    return {"avg_calls_per_task": sum(len(r.actual_tools) for r in results) / total,
            "efficiency_rate": {k: v / total for k, v in counts.items()}}


def compute_tool_success_rate(results: List[TaskEvaluation]) -> Dict:
    """Share of tool calls that ran without an error."""
    logs = [log for r in results for log in r.tool_call_logs]
    successful = sum(log.success for log in logs)
    return {"overall_success_rate": successful / len(logs) if logs else 1.0, "failed_calls": len(logs) - successful}


def numbers_in(text: str) -> List[float]:
    return [float(n) for n in re.findall(r"\d+(?:\.\d+)?", text.replace(",", ""))]


def compute_attribution(results: List[TaskEvaluation]) -> Dict:
    """Did the final answer actually USE a tool's result? Check the tool's main number appears in it."""
    tool_required = [r for r in results if r.requires_external_data]
    attributed = 0
    for r in tool_required:
        answer_numbers = numbers_in(r.output or "")
        for log in r.tool_call_logs:
            tool_numbers = numbers_in(log.output)
            if tool_numbers and any(abs(tool_numbers[0] - a) < 0.05 for a in answer_numbers):
                attributed += 1
                break
    n = len(tool_required)
    return {"attribution_rate": attributed / n if n else 0.0}


def compute_cost(results: List[TaskEvaluation]) -> Dict:
    total_cost = sum(r.total_cost for r in results)
    successful = [r for r in results if r.task_success]
    cost_per_success = total_cost / len(successful) if successful else 0.0
    classification = "Low" if cost_per_success < 0.001 else "Moderate" if cost_per_success < 0.01 else "High"
    return {"total_cost": total_cost, "cost_per_success": cost_per_success, "cost_classification": classification}

def cohens_kappa(a, b):
    """Agreement between two raters, after removing the agreement expected by chance."""
    n = len(a)
    observed = sum(x == y for x, y in zip(a, b)) / n
    labels = set(a) | set(b)
    chance = sum((a.count(l) / n) * (b.count(l) / n) for l in labels)
    kappa = (observed - chance) / (1 - chance) if chance < 1 else 1.0
    return observed, chance, kappa


def describe(k):
    """Common reading of kappa values (Landis & Koch)."""
    for limit, word in [(0, "poor"), (0.20, "slight"), (0.40, "fair"), (0.60, "moderate"), (0.80, "substantial")]:
        if k <= limit:
            return word
    return "almost perfect"
